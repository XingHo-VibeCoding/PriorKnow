# Day 14 · 同伴测试清单

> 用途：拿给同伴照着念。**清单里不要写「怎么做到」** —— 课程第 1131 行说了，
> 「测试者不应被你提示下一步，否则你测到的是你的讲解能力」。
> 所以下面只给**目标**，不给步骤；他卡在哪、问了什么、停了多久，那才是数据。

---

## 一、发给同伴的话（可直接复制）

```
帮我测一个学生作业，同伴互测，大概 10 分钟。

仓库：https://github.com/XingHo-VibeCoding/PriorKnow

## 先把它跑起来（这段是环境，不算测试内容）

需要装 Node.js（22.x 或更新版本都行，https://nodejs.org 下载即可）。

git clone https://github.com/XingHo-VibeCoding/PriorKnow.git
cd PriorKnow/app
npm install
npm run dev

它会打印一个本地地址（形如 http://localhost:5173/），浏览器打开这个地址。

⚠️ 第一次打开时里面是空的 —— 这是正常的，数据存在每个人自己的浏览器里。

## 然后请你做这几件事（我会看着，不提示）

规则只有一条：**遇到任何看不懂、点不动、不知道该干嘛的地方，
先停下来说一句「这里我不会」，别问我。** 你停下来问的每一句，都是我要找的东西。

第 1 件事：看这个页面是干什么的，用一句话告诉我你理解的是什么。

第 2 件事：页面现在是空的。想办法让它有点东西可看。
        （随便加你自己的任务也行。）

第 3 件事：加一条你觉得明天就该做的任务，和一条你觉得不着急的。
        加完之后看看它们的位置有没有变，页面有没有告诉你为什么。

第 4 件事：把新加的那条处理掉（完成或者删除都行）。
        看看页面有没有给你反馈 —— 让你知道刚才那一下到底生效没有。

第 5 件事：页面顶上有个地方能切换看不同的页面，
        都点一遍，看看有没有哪一页你不知道它是干什么的。

做完之后回我三句话：
  ① 你觉得这个产品是干什么的？
  ② 你卡住或者看不懂的地方有哪几个？
  ③ 如果只能改一处，你希望改哪里？
```

## 二、同伴侧运行前提（你自己心里有数就行，不用发他）

| 项 | 值 | 说明 |
| --- | --- | --- |
| Node.js | 22.x 或更新 | 低于 20 Vite 8 起不来 |
| 装依赖 | `npm install` | 约 20 秒，热缓存更快 |
| 启动 | `npm run dev` | 端口 5173（`vite.config.ts` 里定的） |
| 数据 | 每个人**自己的** IndexedDB | 同伴那边初始是空的，与你这边互不相通 |
| 公网地址 | **没有** | 第 15 天才部署上线 |

⚠️ 端口若被占，Vite 会**静默顺延到 5174**，地址栏就会显示 5174 —— 不是版本问题。

## 三、你要记的东西（课程第 1135 行：第一次点击、停顿、提问）

同伴回话时按这三栏记，别急着总结：

| 栏 | 记什么 | 为什么要 |
| --- | --- | --- |
| **第一次点击** | 他第一个点的是哪里 | 第一个点错的地方 = 布局或文案的误导 |
| **停顿** | 哪一步他安静了 3 秒以上 | 停顿 = 在猜「我该干嘛」 |
| **提问** | 他原话问了你什么 | 提问 = 他脑子里的预期和实际不一致 |

再记一条**最容易漏的**：他有没有**不问就自己动手乱试**。
乱试说明界面没给他可走的路，这是比「卡住」更严重的信号。

## 五、我预判会卡住的地方（**假设，不是结论**）

先写下来，测完对照 —— 这样才能分清「真卡点」和「我自己吓自己」。
**别把这些告诉同伴**，否则等于我提示了下一步。

| # | 预判卡点 | 为什么这么猜 | 对应哪个观察项 |
| --- | --- | --- | --- |
| 1 | 打开后一片空白，不知道要干嘛 | 空态只说了「队列是空的」，没有指向「载入示例数据」 | 停顿 |
| 2 | 不知道「今日队列」和「全部任务」的区别 | 两个标签字面意思太像，都是「任务」 | 提问 |
| 3 | 找不到「为什么排第一」的解释 | 理由藏在卡片的「为什么排这里」里，默认不展开 | 第一次点击 |
| 4 | 不敢乱点删除 / 完成 | 删除有确认框但完成没有，可能反过来误触 | 乱试 |
| 5 | 换了页面但不知道换到哪了 | 导航高亮做了，但地址栏变化对普通用户没意义 | 提问 |

**这五条要靠实测证伪或坐实。** 测完之后回来逐条标 ✅ / ❌，
❌ 的那几条才是真正的卡点 —— 我猜错的也算错，照实写。
